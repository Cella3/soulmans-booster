# Soulmans Sound Booster

An ad-free Android media volume booster with a seven-band EQ, Flat/Bass/Vocal/Bright presets, and custom portrait artwork.

![Soulmans Sound Booster icon](Soulmans-Sound-Booster-icon.png)

## Download

- [Install the Android APK](Soulmans-Sound-Booster.apk)
- [Download the Android Studio source](Soulmans-Sound-Booster-source.zip)
- [View the screen concept](Soulmans-Sound-Booster-concept.png)

Android 8 or newer is required. The APK is signed and can update the earlier ClearGain build. To install it, download the APK on your phone and open it.

## Controls

- **BOOST** turns the audio effect on or off and offers 0–12 dB of gain.
- **MEDIA** adjusts Android's media volume for the current phone or Bluetooth output.
- **EQ** has seven controls and four presets. Moving a band creates a custom setting.

The app has no ads, account, analytics, or internet permission. It targets media audio, not phone calls. Android may ignore global effects on some Bluetooth routes, so above-maximum boost must be tested on the device. Start with low gain; high settings can distort sound.

The private signing key is intentionally excluded from this public repository.
